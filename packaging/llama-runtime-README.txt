此目录需要放置 llama.cpp 的 Windows 运行时。

下载地址：
https://github.com/ggml-org/llama.cpp/releases/latest

NVIDIA 显卡：下载 Windows x64 CUDA 12.4 主压缩包和对应的 cudart 压缩包，
将两个压缩包解压到本目录。

仅使用 CPU：下载 Windows x64 CPU 压缩包并解压到本目录。
AMD/Intel 显卡：下载 Windows x64 Vulkan 压缩包并解压到本目录。

完成后必须存在：llama\llama-server.exe
不要在本目录内再套一层压缩包目录。
